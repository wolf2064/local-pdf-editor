ローカルPDFエディター v4.11（Chrome / Edge 拡張機能）
==========================================
PCに保存したPDFをブラウザーで開き、そのまま編集・保存・印刷できる拡張機能です。
処理はすべてお使いのPCの中で行い、PDFや入力した内容を外部に送信することはありません（インターネット未接続でも動作します）。
開けるのはPCに保存したPDFだけです（インターネット上のPDFは扱いません）。

【主な機能】
- 内容の編集: PDF内の文字の書き換え、図形（ベクター）の移動・拡大縮小・回転・色の変更・削除・複製、配置順の変更
  ※ スキャンした画像の文字認識（OCR）や画像の編集には対応していません
- 注釈: 直線・矢印・四角形・丸・折れ線・多角形・雲形・テキスト（ゴシック・明朝・等幅）・手書き、画像スタンプ、日付印
  Acrobat などで作った注釈の色・太さ・塗りなどの変更、直線・折れ線・多角形・雲形の頂点の編集
  複数選択・グループでの移動／回転／拡大縮小、コピー＆貼り付け、配置順の変更、既存のコメントの編集
- ページ: 回転・並べ替え・挿入・削除・抽出・空白ページの挿入、ほかのタブのPDFとの間でのページのコピー＆貼り付け（ページの整理）
- しおり: 一覧表示・移動・追加・名前の変更・削除
- 文書プロパティ: タイトル・作成者などの編集、編集ロック（権限パスワード）の解除
- 印刷: 範囲・用紙・倍率・向き・とじしろ・片面／両面を指定して印刷（プレビュー付き）
- 注釈埋め込み: 注釈を見た目どおりにページの内容へ描き込む
- 保存: 上書き保存／名前を付けて保存。保存していない変更があるときは、閉じる前に確認します
  ダブルクリックで開いたPDFの最初の［保存］では、保存先の選択画面で Ctrl+V（元のPDFの場所を貼り付け）→［保存］で元のPDFに上書きできます

【インストール後の設定】
1. 拡張機能の管理画面（Chrome: chrome://extensions ／ Edge: edge://extensions）でこの拡張機能の「詳細」を開く
2. 「ファイルの URL へのアクセスを許可する」をオンにする（PCに保存したPDFを開くために必要です）
これで、PCのPDFをブラウザーで開くと、自動でこのエディターで開きます。
ツールバーのアイコンを押すと、表示中のPDFをエディターで開くか、空のエディターが開きます（「開く」またはドラッグ＆ドロップでPDFを選べます）。

【主な操作】
- 左のツール欄で、選択・内容を編集・注釈選択・各種注釈のツールを切り替えます（右パネルの「操作のヒント」に一覧があります）
- Ctrl+Z / Ctrl+Y: 元に戻す／やり直し、Ctrl+S: 保存、Ctrl+P: 印刷、Delete: 削除
- 「内容を編集」: 文字や図形をクリックして選択。ドラッグで移動、ハンドルで拡大縮小・回転、文字はダブルクリックかEnterで書き換え

【権限について】
- ファイルの URL へのアクセス: PCに保存したPDFを読み込むため（読み込んだPDFは外部に送信しません）
- webNavigation: PCのPDFを開いたとき、このエディターで開き直すため
- downloads: 編集したPDFを保存するため
- clipboardRead: コピーした画像をスタンプとして貼り付けるため
- storage: 表示や日付印などの設定を保存するため
